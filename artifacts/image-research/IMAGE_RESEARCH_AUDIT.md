# Projects image research audit

Reviewed 15 November 2026 (Asia/Karachi). Read all seven required project documents and the installed Next.js image/component guides before implementation. Research used web and image search, publisher pages, official developer sites and Wikimedia Commons. The search service does not identify its image-search provider; this report does not claim direct Google Images access.

**Result: one category B location photograph implemented; eight text panels. No category A photograph established.** No reviewed source established a connection between a photograph and SAS Construction. Public accessibility and a matching place name were not treated as permission or proof of SAS execution. No permission was requested from publishers and none was supplied by the client.

Classification applies to the specific candidate, not the existence of the locality. A means verified SAS photograph with permission; B means verified locality without SAS execution evidence; C means photograph/site identity or authenticity remains insufficiently verified. B still requires a separate reuse authorization. Sources below are image-containing publisher pages unless a direct file is specified. Unreviewable or ambiguous candidates remain C, even where the page names a plausible locality.

## Implementation scope

Existing featured composition, project ordering, index rows, filters and detail dialogs retained. Text media panels use the existing palette and fonts. All nine generic image references removed from project data. Legacy assets are not rendered by the Projects section; no unverified replacements were downloaded. Existing Hero, About and Services were not edited by this task.

Descriptions and scope bullets in the project register were reduced to the supplied source wording where previous text asserted unsupported pipe materials, interlocking paver types, equipment methods or other details. Unconfirmed locations remain unconfirmed.
